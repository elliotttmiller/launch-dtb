# UI Experience Design Workflow

Do not design isolated screenshots when the feature is a user flow.

1. Identify user goal, entry/exit points and system owners.
2. Model happy, alternate, loading, empty, validation, failure, recovery, cancellation, authorization and terminal success states that are relevant.
3. Define state transitions and server/provider authority for each state.
4. Inspect existing components/tokens before creating primitives.
5. Implement one semantic responsive composition where possible.
6. Critique in order: accessibility, information hierarchy, commerce clarity, content, interaction/state completeness, responsive integrity.
7. Fix discovered issues before the next pass when practical.
8. Verify keyboard/focus, reduced motion, zoom/text expansion, dynamic content and intermediate widths.
