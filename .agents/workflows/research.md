# Research Workflow

For current external claims, use live research capabilities when available.

- Define the question, timeframe and evidence standard.
- Prefer primary/official sources for factual product/provider claims.
- Use credible independent/trade/statistical sources for market interpretation.
- Use community sources for sentiment only and label their evidentiary weight.
- Corroborate important or contested claims.
- Separate retrieved fact, inference and recommendation.
- Cite every material external claim in the user-facing result when the platform supports citations.
- If retrieval capability is unavailable, state the limitation rather than presenting training recall as current fact.
