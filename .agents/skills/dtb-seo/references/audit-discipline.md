# SEO Audit Discipline

Every finding must be evidenced by a file/symbol actually read, a command actually run, or runtime output actually retrieved. Never report common ecommerce issues as if observed.

For each finding record severity, category, scope, exact evidence and owning fix layer. Separate source-verifiable claims from runtime/search-engine facts requiring live fetch/browser/Search Console/Lighthouse/structured-data verification.

Never fabricate product names, SKU/MPN/GTIN, price, stock, ratings, review counts, slugs or compatibility. Scope template-wide findings only when shared implementation proves the scope.

Persist substantial audit artifacts under `docs/work/<task-id>/`.
