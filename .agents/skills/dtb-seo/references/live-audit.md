# Live Audit Reference

Use live retrieval/browser capabilities only when available and distinguish them precisely:

- fetched HTML/text can verify served metadata/schema/static content;
- browser rendering/interaction is required for visual/interactive behavior;
- measured performance requires an actual measurement tool;
- search-engine indexation requires search-engine tooling/evidence.

Check content pollution, pricing/availability/schema consistency, stale promotional content, trust/compatibility claims, route/template consistency and conversion friction. Quote the exact fetched/runtime evidence for every live finding. Do not infer visual overlap from text-only fetches.
