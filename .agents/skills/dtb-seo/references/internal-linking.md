# Internal Linking Reference

Derive the URL/template inventory from active React routing plus sitemap eligibility source before recommending links.

Prefer existing relationship authorities:

- WooCommerce/catalog upsell/related relationships for PDP-to-PDP relationships.
- Canonical schematic/part mapping helpers for schematic/parts navigation.
- Visible breadcrumb links consistent with breadcrumb structured data.

Do not hard-code a second relationship graph in React. Do not recommend editorial/indexable inbound links to session/account/cart/checkout/order/status/preview/operator surfaces. Compatibility language in anchors requires verified compatibility evidence.

For candidate relationships weigh catalog proximity, verified functional compatibility, intent alignment and real term overlap; do not invent scores when evidence is missing.
