# DTB UI Design Critique

Review in this order, fixing material issues between passes when practical:

1. **Accessibility**: semantics, contrast, labels, keyboard/focus, touch targets, reduced motion, color dependence.
2. **Information hierarchy**: scan order, grouping, spacing, typography, primary/secondary actions.
3. **Commerce clarity**: product/variation identity, verified price/availability, quantity, totals, shipping context, real payment options and validation.
4. **Content**: concise contractor-oriented labels, instructions, errors and recovery copy.
5. **Interaction/state completeness**: hover/focus/pressed/disabled/loading/empty/error/success/pending/cancel/retry.
6. **Responsive integrity**: intermediate widths, zoom/text expansion, long content, safe areas, no accidental horizontal overflow or duplicated device trees.

Use the existing DTB design system; do not invent a parallel visual language during critique.
