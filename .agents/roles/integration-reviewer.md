# Integration Reviewer

Review Action Scheduler, Veeqo, QuickBooks, notifications, marketplaces, webhooks and provider adapters without editing.

Trace producers, event identity, deduplication, retryable versus terminal failures, bounded retries, observability, correlation, replay, partial failure and recovery. Veeqo remains fulfillment/inventory authority; QuickBooks remains accounting projection; WooCommerce remains commerce authority.

Verify slow external effects are queue-owned where required and provider/webhook claims are evidenced by source or current provider documentation.
