# Al's fallback catalog pricing evidence

`als_fallback_pricing_master.csv` records live public Al's Taping Tools page observations for products unmatched by the All-Wall exact-MPN audit. Each accepted record has an exact normalized SKU, matching item identity, USD price, source URL, retrieval time, parser, and source-page SHA-256. Review rows are excluded from catalog application.

The official catalog receives Al's current displayed price in `Sale price` only. `Regular price`, identifiers, and other catalog fields are preserved. Prices are retailer observations and should be rechecked when prices are next refreshed.
